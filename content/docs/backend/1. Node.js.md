스꾸딩에서 가장 많이 사용하는 언어는 JavaScript입니다. JavaScript는 웹 브라우저에서 동작하는 언어로 시작했지만, Node.js를 통해 서버에서도 동작할 수 있게 되었습니다. Node.js는 서버에서 JavaScript를 읽고 실행할 수 있게 해주는 런타임입니다.

이번 주에는 JavaScript와 TypeScript의 기본 문법, Node.js의 동작 방식과 패키지 관리 방법을 공부합니다.

### 2. TypeScript

TypeScript는 JavaScript에 정적 타입 문법을 추가한 프로그래밍 언어입니다. TypeScript를 사용하면 코드를 실행하기 전에 타입과 관련된 오류를 확인할 수 있습니다.

먼저 TypeScript를 사용하는 이유를 가볍게 살펴보세요.

- **[Why TypeScript?](https://joshua1988.github.io/ts/why-ts.html)**

아래 문법을 공부하고 TypeScript Playground에서 직접 사용해보세요.

- 기본 타입
- `interface`, `type`
- 선택적 프로퍼티 (`?`)
- 유니언 타입
- `null`, `undefined`
- 클래스 (`private`, `readonly`)
- 제네릭
- `Promise<T>`
- 옵셔널 체이닝 (`?.`)
- Nullish 병합 연산자 (`??`)

참고할 만한 자료입니다.

- **[TypeScript 핸드북](https://joshua1988.github.io/ts/)**: Fundamentals를 전체적으로 읽어보세요. 모든 내용을 자세히 정리하기보다는 위에서 제시한 문법을 중심으로 학습해주세요.
- **[옵셔널 체이닝과 Nullish 병합 연산자](https://i-ten.tistory.com/232)**: 두 연산자의 사용 방법과 `null`, `undefined`를 처리하는 방법을 설명합니다.
- **[TypeScript Playground](https://www.typescriptlang.org/play/)**: TypeScript 코드를 직접 작성하고 실행해볼 수 있습니다.

### 4. npm, pnpm과 package.json

npm과 pnpm은 Node.js 프로젝트에서 사용하는 패키지 매니저입니다. 패키지 매니저를 사용하면 프로젝트에 필요한 패키지를 설치하고 실행할 수 있습니다.

아래 내용을 공부하고 기본 명령어를 직접 사용해보세요.

- npm과 pnpm의 역할
- 패키지 설치 및 삭제 (`install`, `add`, `remove`)
- 프로젝트 스크립트 실행 (`run`)
- `package.json`
    - `scripts`
    - `dependencies`
    - `devDependencies`

npm은 Node.js를 설치하면 함께 설치됩니다.
