지금까지 배운 내용을 바탕으로 코드당의 실제 작업에 참여해봅시다!

## Good First Issue란? 🚀

Good First Issue는 프로젝트에 처음 기여하는 사람이 코드와 개발 과정을 익히기 좋은 작은 작업입니다. 비교적 범위가 명확하고 난이도가 낮아, 실제 프로젝트에 처음 참여할 때 시작점으로 삼기 좋습니다.

## 이번 주에 할 일

멘토가 배정한 Good First Issue를 확인하고 직접 해결해보세요.

- Issue와 관련된 코드를 찾습니다.
- 코드를 수정하고 테스트합니다.
- 필요한 경우 Bruno로 API의 동작을 확인합니다.
- Pull Request를 작성하고 리뷰를 받습니다.

Branch, Commit, Pull Request 작성 방법은 **[코드당 Contributing Guide](https://github.com/skkuding/codedang/blob/main/CONTRIBUTING.md)** 와 **[개발 프로세스](https://docs.codedang.com/dev/intro/process.html)** 를 참고해주세요. 막히는 부분이 있다면 혼자 오래 고민하기보다 멘토나 팀원들에게 질문해도 좋습니다.
