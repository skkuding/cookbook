## 공부할 내용 📚

### 1. Git과 GitHub

Git과 GitHub가 무엇인지, 둘의 차이가 무엇인지 알아봅니다.

- Repository
- Local과 Remote
- Working Directory, Staging Area, Commit

### 2. Git 기본 명령어

다음 명령어가 어떤 상황에서 사용되는지 알아보세요.

- `git clone`
- `git branch`
- `git switch`
- `git add`
- `git commit`
- `git push`
- `git pull`

### 3. GitHub 협업

다음 개념이 무엇인지와 서로 어떻게 이어지는지 알아보세요.

- Branch
- Pull Request
- Code Review
- Merge
- Conflict
- Rebase

Rebase는 어떤 목적으로 사용하는지 개념만 가볍게 살펴보면 됩니다.

### 4. Codedang Convention

프로젝트마다 Branch와 Commit을 작성하는 규칙이 다를 수 있습니다. Codedang에서는 어떤 규칙을 사용하는지 **[Contributing Guide](https://github.com/skkuding/codedang/blob/main/CONTRIBUTING.md)** 에서 가볍게 살펴보세요.

- Branch Convention
- Commit Convention
