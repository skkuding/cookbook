지난주까지는 Restaurant 데이터를 Service의 배열에 저장했습니다. 하지만 배열에 저장한 데이터는 서버가 종료되면 사라지고, 여러 서버에서 데이터를 함께 사용하기도 어렵습니다.

이번 주에는 관계형 데이터베이스의 기본 개념과 SQL을 공부하고, Docker로 PostgreSQL을 실행하여 데이터를 직접 저장하고 조회해봅니다.

- Schema
- Primary Key와 Foreign Key
- Constraint
- Unique Constraint
- Table 간의 Relation

## 실습 🎈

Docker로 PostgreSQL을 실행한 뒤 Restaurant 데이터를 직접 저장하고 확인해봅시다.

### 1. PostgreSQL 실행

Docker가 설치되어 있지 않다면 먼저 **[Docker 설치 가이드](https://docs.docker.com/get-started/get-docker/)**를 참고하여 설치합니다.

이번 실습에서는 환경을 쉽게 통일할 수 있도록 Docker를 사용하여 PostgreSQL을 실행합니다.
이미 다른 방법으로 PostgreSQL을 사용하고 있다면 해당 환경을 사용해도 됩니다.

다음 명령어로 PostgreSQL 컨테이너를 실행합니다.

```bash
docker run --name restaurant-postgres \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=restaurant \
  -p 5432:5432 \
  -d postgres:17
```

- **[PostgreSQL Docker Official Image](https://hub.docker.com/_/postgres)**: PostgreSQL 이미지의 실행 방법과 환경 변수를 확인할 수 있습니다.

실행 중인 컨테이너를 확인합니다.

```bash
docker ps
```

### 2. PostgreSQL 접속

컨테이너 안의 `psql`을 사용하여 `restaurant` 데이터베이스에 접속합니다.

```bash
docker exec -it restaurant-postgres psql -U postgres -d restaurant
```

### 3. Table과 데이터 확인

Restaurant 테이블을 생성합니다.

```sql
CREATE TABLE restaurants (
  id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  address VARCHAR(255) NOT NULL,
  phone VARCHAR(20) UNIQUE
);
```

테이블 목록과 구조를 확인합니다.

```text
\dt
\d restaurants
```

Restaurant 데이터를 추가하고 조회합니다.

```sql
INSERT INTO restaurants (name, address, phone)
VALUES ('봉수육', '경기 수원시 장안구 율전로108번길 11 1층', '0507-1460-0903');

SELECT * FROM restaurants;
```

`UPDATE`를 실행하여 데이터가 어떻게 변경되는지도 확인해보세요.

### 4. Relation 확인

Restaurant와 Review의 관계를 표현하는 테이블을 생성합니다.

```sql
CREATE TABLE reviews (
  id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  restaurant_id INTEGER NOT NULL REFERENCES restaurants(id),
  content TEXT NOT NULL
);

INSERT INTO reviews (restaurant_id, content)
VALUES (1, '맛있어요');
```

`restaurant_id`가 `restaurants` 테이블의 `id`를 참조하는 과정을 확인하고, 두 테이블을 `JOIN`하여 조회해보세요.

```sql
SELECT restaurants.name, reviews.content
FROM restaurants
JOIN reviews ON restaurants.id = reviews.restaurant_id;
```

마지막으로 Review를 먼저 삭제한 뒤 Restaurant을 삭제해보세요. 삭제 순서를 바꾸면 어떻게 되는지도 확인해봅니다.

```sql
DELETE FROM reviews WHERE restaurant_id = 1;
DELETE FROM restaurants WHERE id = 1;
```
