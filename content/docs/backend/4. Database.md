지난주까지는 Restaurant 데이터를 Service의 배열에 저장했습니다. 하지만 배열에 저장한 데이터는 서버가 종료되면 사라지고, 여러 서버에서 데이터를 함께 사용하기도 어렵습니다.

이번 주에는 관계형 데이터베이스와 PostgreSQL의 기본 개념을 공부하고, SQL을 직접 작성해봅니다.

## 공부할 내용 📚

### 1. 관계형 데이터베이스

데이터베이스와 DBMS가 무엇인지 알아보고, 관계형 데이터베이스가 데이터를 어떤 형태로 저장하는지 공부합니다.

- Database와 DBMS
- 관계형 데이터베이스
- Table, Row, Column
- Schema
- Primary Key와 Foreign Key
- Constraint
- Unique Constraint
- Table 간의 Relation

아래 자료를 참고하거나 필요한 내용을 자유롭게 검색하여 학습해보세요!

- **[데이터베이스란?](https://www.oracle.com/kr/database/what-is-database/)**: Database Defined, Types of Databases, DBMS 부분을 중심으로 읽어보세요.
- **[관계형 데이터베이스 개념](https://wikidocs.net/253214)**: Table, Row, Column과 Primary Key, Foreign Key, Unique Constraint의 개념을 살펴보세요. Index는 다음 주차에 공부하므로 이번에는 넘어가도 됩니다.
- **[데이터베이스 관계](https://s-y-130.tistory.com/141)**: `스키마란?` 부분을 읽고, Primary Key와 Foreign Key가 테이블을 연결하는 방법과 1:1, 1:N, N:M 관계를 중심으로 살펴보세요.

### 2. SQL

SQL은 관계형 데이터베이스에서 데이터를 정의하고 조회하거나 변경할 때 사용하는 언어입니다. 다음 SQL 문법의 역할과 기본적인 사용 방법을 공부합니다.

- `CREATE TABLE`
- `INSERT`
- `SELECT`
- `WHERE`
- `UPDATE`
- `DELETE`
- `JOIN`

아래 자료를 참고하여 기본 문법을 익혀보세요.

- **[SQL Tutorial](https://www.w3schools.com/sql/)**: SQL Intro와 Syntax, SELECT, WHERE, INSERT, UPDATE, DELETE, JOIN, CREATE TABLE 부분을 살펴보세요.

### 3. PostgreSQL

PostgreSQL이 어떤 관계형 데이터베이스 관리 시스템인지와 주요 특징을 가볍게 살펴봅니다.

- **[What is PostgreSQL?](https://www.postgresql.org/about/)**: PostgreSQL의 특징과 사용 목적을 살펴보세요.
- **[The SQL Language](https://www.postgresql.org/docs/current/tutorial-sql.html)**: PostgreSQL에서 테이블을 생성하고 데이터를 추가, 조회, 수정, 삭제하는 방법을 살펴보세요.

## 실습 🎈

**[SQL 실습](https://www.w3schools.com/sql/trysql.asp?filename=trysql_select_all)** 에서 기본 쿼리를 직접 실행해봅시다.

- `CREATE TABLE`로 새로운 Table을 생성합니다.
- `SELECT`로 데이터를 조회합니다.
- `WHERE`로 원하는 데이터만 조회합니다.
- `INSERT`, `UPDATE`, `DELETE`로 데이터를 추가, 수정, 삭제합니다.
- 서로 관계가 있는 두 Table을 `JOIN`하여 조회합니다.

각 쿼리를 실행한 뒤 Table의 데이터가 어떻게 달라지는지 확인해보세요.
